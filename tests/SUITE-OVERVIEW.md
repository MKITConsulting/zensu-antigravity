# Test suites

`bash tests/run-all.sh` discovers every `tests/structure/test-*.sh`, then runs the
config-gate self-check and offline promptfoo suite. Unit registries reject missing,
cancelled, unexpectedly skipped or silently removed test cases.

The native adapter suite covers immutable binding, helper authorization, review reports,
worker arguments and real validated Stop-state behavior. Canonical suites cover TDD modes,
full-suite and acceptance gates, secret/source/mutation gates, work orders, review convergence
and recovery. `autopilot-adopt-cli` and `autopilot-release-cli` exercise their separate owner
activity windows and refusal conditions. `test-zen-mode.sh` covers Zen session behavior.

The real-host suite is separate: `ZENSU_LIVE_AGY=1 bash evals/promptfoo/live/run-live.sh`.
No skipped or unavailable native probe establishes a passing live verification.
