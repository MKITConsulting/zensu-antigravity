# Evidence discipline

Only claim an action, result or invariant that the current run actually observed. Command exit status, exact tree identity, receipt generation, the checked surface and residual gaps belong together. A green isolated test is not proof that a native host loaded the hook; a launched process is not a successful result; a screenshot is not data correctness.

The plugin supplies evidence discipline through its native lifecycle hooks, skill content and the plugin-owned `rules/AGENTS.md` channel verified on agy 1.4.2. Installed rules steer the model even without a hook event; they do not replace runtime proof or enforcement. The installer ships product policy without editing the user's workspace-root AGENTS.md. Editing that user-owned file still requires authorization.

The evidence runner executes the real command, captures bounded output and records tree-bound receipts. Full-suite and acceptance gates reject absent, failed, partial, stale, interrupted or mismatched evidence. CI handoff is explicitly deferred until that CI run is observed. Failed or unavailable checks remain visible; do not substitute mocks or hand-written receipts for required dependencies.

Reviews retain per-finding path, line, severity and evidence. Native reviewer contexts are distinct, with verified child provenance; convergence still does not prove correctness. Snapshot validation proves exact bytes of enumerated files, not all possible evidence. For UI criteria, verify behavior/data and visual appearance separately. The detailed execution protocol lives in `skills/tdd/references/audit.md`, `skills/tdd/references/review-chain.md` and `skills/verify-feature/SKILL.md`.
