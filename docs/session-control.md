# Native Session Control

The host payload's native `conversationId` binds the session. `hooks/antigravity/session-bootstrap.js` initializes the private Session Control record and injects `{plugin_root}`, `{project_root}`, `{conversation_id}` and `{session-helper}`. The helper is an absolute shell-quoted `bash .../session-helper.sh --session ...` prefix. Missing or mismatched binding fails closed; no ambient shell export or guessed latest session is authority.

All stateful operations use the wrapper as a standalone literal command. The command guard validates its exact arguments and issues a per-call receipt. `--stdin-file '<absolute-file>'` before `--` binds the input file's digest; it does not require shell redirection. The wrapper supplies native identity, project root and plugin-data to the engine-neutral runtime. Receipts, runtime digest, current generation, session and tree must agree.

`/zensu-adopt-session` reports an incompatible runtime lineage, then adopts only after explicit confirmation. Root restoration is a separate report/confirm mode; it restores control-directory structure, not removed Git work. Reanchor keeps the canonical same-repository and exclusive-live-session requirements. Native transcript/index snapshots cannot prove exclusive ownership; an unavailable live-session registry must produce `live-sessions-unverifiable`, never an invented successful reanchor. Use a fresh conversation in the correct worktree when proof is unavailable.

The native CLI executes registered read-only profiles through `invoke_subagent`. Actual parent step, child metadata and initial parent linkage establish the child principal before its first tool call; a normal, fully idle native child Stop records completion. TDD receipts bind the current ticket/tree/role; plan/PR workers bind their exact-file/safe-root private lease. No source-host SubagentStart/SubagentStop event or caller-supplied child ID is synthesized. IDE execution remains unverified.

`/zensu-session-trail` reads the local native summary database, last-conversation cache and bounded transcript snapshots. It reports their evidence source and uncertainty, supports explicit handoff and records lineage in plugin data. A lineage edge is not exclusive ownership. Account labels, task chips, window ownership, archive-release protection and native forks have no verified equivalent. See `skills/session-trail/SKILL.md` for exact supported operations.
